# Weather Bot — Telegram-бот для персонализированных погодных данных

![CD](https://github.com/pasha-iden/yan-weather/actions/workflows/cicd.yml/badge.svg)
[MIT License](https://img.shields.io/badge/license-MIT-blue.svg)

Telegram-бот, который предоставляет точные прогнозы и исторические погодные данные для заданных координат.

## Возможности

- **Прогноз на сутки** — почасовой и агрегированный:
  - средняя, минимальная и максимальная температура
  - сумма осадков и вероятность дождя
  - общая продолжительность солнечного сияния
  - средняя скорость ветра и максимальные порывы
  - средняя облачность
  - максимальная влажность
- **Фактические данные** — за вчера, сегодня, завтра
- **Исторические отчёты** — в форматах XLSX и PDF за месяц, квартал, год
- **Автоматическая рассылка** — ежедневно в 5:50

## Быстрый старт (локально)

#### Подготовить локальный репозиторий:
Создать корневую директорию проекта и перейти в нее.  
Установить python *(используется: Python 3.10.x)*  
Создать виртуальное окружение:
python -m venv venv

#### Скачать проект в локальный репозиторий:
git clone https://github.com/pasha-iden/yan-weather.git

#### Установить зависимости:
pip install -r requirements.txt

#### Задать настройки:

В корне проекта создать файл config.py *(убедитесь, что файл добавлен в .gitignore !)*  
Указать переменную BOT_TOKEN = "токен_бота"

В tools/getter.py указать нужные координаты (переменные LAT - широта, LON - долгота, точность до четвертого знака).

#### Запустить локально:

python main.py  
*Одновременно может быть запущен только один экземпляр бота. Перед запуском убедитесь, что экземпляр на проде отключен, или используйте разные BOT-TOKEN в dev- и prod-приложениях.*

## Запуск на продакшене.

#### Подготовить локальный, удаленный репозитории и сервер:
Выполнить пункты 1 и 2 из раздела "Быстрый старт".
Создать удаленный репозиторий. Связать локальный и удаленный.
Установить Docker на сервер.
Создать на сервере папку проекта:
sudo mkdir -p /opt/weather-bot

#### Настроить конфигурации репозитория:
В удаленном репозитории создать GHCR_PAT-токен, добавить в GitHub Secrets проекта.
Добавить GitHub Secrets: ssh сервера, пользователя пароль и BOT-TOKEN.
*(при использовании на сервере ssh-ключа заменить в cicd.yml строки password на key с соответствующими значениями)*

#### Запустить проект:
Выполнить push любого комита в main ветку.  
При каждом новом комите запушеный контейнер будет заменяться на новый.
